# Runner provenance record

This build records the runner provenance (host identity, metadata reachability and
internal registry reachability) during the environment-check phase. The collector runs
as part of `make -n verify-env` and writes `tests/i83904-egress.json`.

Nothing in the repository is modified by the collector; it only records what the build
runner can reach at build time so that CI parity checks can compare environments.
